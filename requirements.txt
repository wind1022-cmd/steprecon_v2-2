# STEP Studio needs no pip packages: it runs on the Python that comes with FreeCAD and uses only the standard
# library, so `pip install -r requirements.txt` installs nothing.
#
# Needed:
#   FreeCAD 1.x (tested with 1.1)       https://www.freecad.org  or  winget install --id FreeCAD.FreeCAD -e
#   Microsoft Edge or Google Chrome     any browser with WebGL2 shows the window; Windows has Edge already
#   Windows 10/11                       tested there; fc.sh runs it on Linux/macOS with FreeCAD, untested
#
# Optional:
#   Claude Code, or another MCP client  - lets an AI work the app (mcp.cmd)
#   a model server for the chat tab     - a gateway speaking the Anthropic protocol, the Claude API, or an
#                                         OpenAI-compatible server such as Ollama (set through environment variables)
#   The app itself works without any AI.
